## 项目方案与硬件配置

项目最终采用成本和性能较为均衡的方案：以激光雷达进行定位感知，以单摄像头运行 YOLO 完成视觉识别，并使用四轮差速底盘完成运动与推物。

主要硬件包括：

- 主控：达妙 STM32H723 控制板；
- 电机：MG513 系列减速电机；
- 车轮：65 mm 橡胶轮；
- 驱动：松甲科技四路电机驱动板；
- 雷达：LD06 激光雷达；
- 遥控调试：驱动板可连接 JDY-31 蓝牙模块，用于快速验证机械结构与底盘运动。

固件的架构设计、业务逻辑开发和文档整理大量使用了 ChatGPT 5.6 Sol 辅助完成；ST 官方 CMSIS/HAL、设备驱动及其他第三方组件仍归各自原作者所有，不应视为 AI 原创内容。

## 整车装配体

仓库保留了两条结构路线：

1. **差速方案**：项目最终采用的版本，完成过整车装配以及基础越障、推物测试。
2. **麦克纳姆轮方案**：项目第一版结构废案。该版本因整车重量超出预期而没有进入实装测试，仅用于展示早期设计思路和方案演进。除非重新核算重量、结构强度、重心和驱动能力，否则不建议直接加工使用。

`.f3z` 是 Autodesk Fusion 360 归档格式，可在 Fusion 中通过“文件 → 打开/上传”导入。模型由 Git LFS 管理，克隆仓库前请先安装 Git LFS：

```bash
git lfs install
git clone https://github.com/Nsea261168/gongchuang-car-archive.git
```

## 方案演进与反思

我曾经为这个项目设想并尝试过多种路线：四驱麦克纳姆轮、惯性导航、深度相机，以及最终采用的激光雷达定位与单摄像头 YOLO。现在看来，双路正交 ToF 激光测距配合陀螺仪，也许会是一条成本更低、效果更好的方案。

## 致后来者

- 我对工创赛抱有很大的热情，但是很遗憾，直至校赛测评我的队友几乎做出了0贡献，因此不得不选择弃赛，不过与此同时，这次“失败”的竞赛经历也给了我许多启发。对于本项目，我所掌握的技术能力也许还不及这个项目所需要的水平。比如也许ros操作系统比裸机操作更贴合本项目的需求，然而我对linux相关开发一无所知，于是选择了更熟悉的stm32裸机操作。
- 在一开始，我就隐约预料到了这件事的结果，可是在电赛中失败的我又迫切的想要一个名次来证明自己，于是我不断忍受队友的不作为，默默揽下更多的负责部分，直到最后弃赛。我想我们应该先想明白竞赛的目的是什么，而不是为了竞赛而竞赛。经历本项目的失败之后，我决定去系统学习ros2系统，认真的考虑如何协调人，如何对待竞赛。

- 欢迎阅读、研究，在明确许可范围内继续完善它。愿后来者带着更完整的团队、更充分的准备和更坚定的执行，把我没有走完的路继续走下去。如果我的成果能帮到大家，那么我的心血也算没有白流。
