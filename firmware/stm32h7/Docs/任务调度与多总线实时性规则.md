# 工创赛智能救援车任务调度与多总线实时性规则

本文规定 H7 如何调度 LCD、三路 UART 与一路 SPI。它是[智能救援小车最终骨架计划](智能救援小车最终骨架计划.md)的实时性补充；只定义数据流与安全规则，不替代具体设备协议。

## 1. 总原则

1. **H7 是唯一决策中心。** 视觉、雷达、IMU 和松甲反馈只产生数据快照；只有 H7 的底盘控制周期可以产生最终 `vx / vy / wz`。
2. **中断只收数据，不做业务。** UART/SPI 中断或 DMA 回调只搬运字节、更新环形缓冲写指针、记录接收时间和置“有新数据”标志；禁止在中断中解析完整协议、刷新 LCD、运行 PID 或发送连续电机命令。
3. **主循环只消费最新有效快照。** 对连续流数据不排队处理旧帧：视觉、雷达和松甲反馈解析完成后覆盖上一份有效结果；任务状态机不等待某一路数据。
4. **控制优先于显示。** LCD 只能低频、按需刷新，绝不能占用 50 Hz 底盘安全周期。
5. **安全优先于任务。** 任一关键数据过期、通信异常或任务退出时，安全层可以覆盖任务状态机的输出为零。

## 2. 总线职责与数据所有权

| 接口 | 设备 | 数据方向 | 产生的数据快照 | 写入最终底盘命令？ |
| --- | --- | --- | --- | --- |
| UART1 | 泰山派视觉 | 泰山派 -> H7 | 最近 5 个目标、夹爪区状态、视觉时间戳 | 否 |
| UART5 | LD06 雷达 | 雷达 -> H7 | 点云/障碍、定位结果、雷达时间戳 | 否，只能限速或停车 |
| UART7 | 松甲驱动板 | H7 <-> 松甲 | 编码器、链路时间戳；接收最终运动命令 | 是，且只能由底盘安全层发送 |
| SPI | BMI088 IMU | H7 <-> IMU | 姿态、航向、时间戳 | 否 |
| LCD | H7 -> 显示器 | H7 -> LCD | 仅显示状态 | 否 |

旧 UART3 泰山派 `A5 5A` 协议独立保留，不参与本表的运动闭环，也不得和 UART1 视觉帧混用。

## 3. 协作式主循环的执行顺序

工程保持一个主循环，所有服务都必须一次完成小步工作后立即返回：

```text
每一圈主循环：
  1. 读取当前 now_ms
  2. 消费各总线接收缓冲（每路有固定处理预算）
  3. 到期则更新 IMU 姿态
  4. 到期则处理雷达快照、定位与障碍物
  5. 到期则消费最新视觉快照与目标关联
  6. 到期则运行救援任务状态机，生成“期望 vx/vy/wz”
  7. 到期则运行底盘安全与控制，生成“最终 vx/vy/wz”并下发 UART7
  8. 到期则刷新 LCD 中已变化的行
  9. 扫描按键与推进当前诊断/测试任务
```

任何一步不得通过 `HAL_Delay()`、等待串口收满、等待 SPI 完成或循环等待电机反馈阻塞下一步。时间判断统一使用无符号差值：

```c
if ((uint32_t)(now_ms - last_ms) >= period_ms)
{
    last_ms = now_ms;
    /* 只执行一次周期动作 */
}
```

## 4. 周期、处理预算和优先级

| 优先级 | 模块 | 目标频率 | 最大间隔 | 规则 |
| --- | --- | ---: | ---: | --- |
| P0 | 硬件中断/DMA | 事件触发 | 尽快 | 仅字节搬运、时间戳、溢出计数 |
| P1 | 底盘安全与 UART7 下发 | 50 Hz | 20 ms | 最终速度限幅、超时停车、发送松甲命令 |
| P1 | IMU SPI 更新 | 100 Hz | 10 ms | 更新航向快照；失败不得阻塞控制 |
| P2 | UART7 编码器解析 | 每主循环增量 | 20 ms 内 | 只保留最新反馈，服务控制安全判断 |
| P2 | UART5 雷达解析/避障 | 10-20 Hz | 50-100 ms | 增量解析点云，输出定位/障碍快照 |
| P2 | UART1 视觉解析/目标关联 | 20 Hz | 50 ms | 只使用最新 CRC 正确的 65B 视觉帧 |
| P3 | 救援状态机 | 20 Hz | 50 ms | 选择目标并输出期望运动，不直接写 UART7 |
| P4 | LCD | 4-10 Hz | 100-250 ms | 仅刷新变化区域，不得整屏高频重画 |
| P4 | 菜单/按键 | 每主循环 | 低延迟 | 只产生事件，任务一次消费一个事件 |

如果某一轮主循环耗时异常，下一轮仍先执行 P1 的安全和控制，不得为了补齐旧视觉帧、旧点云或 LCD 刷新而连续追赶历史周期。

## 5. UART1：泰山派视觉调度规则

### 接收与解析

- UART1 只接收泰山派单向视觉数据，115200/8N1。
- 视觉端 20 Hz 发送固定 **65B** 帧：`A5 5B | VER | TYPE | SEQ | capture_ms | target[5] | jaw_status | CRC16`。
- 接收中断将字节放入环形缓冲；主循环查找帧头、固定读取 65B、校验 CRC-16/CCITT-FALSE。
- CRC 错误、版本不匹配、类型不匹配或缓冲溢出时丢弃本帧并计数；不得修改上一份有效视觉快照。
- 有效帧写入双缓冲或“写完后一次切换”的快照，避免任务状态机读到半帧数据。

### 消费与超时

- 视觉消费周期：20 Hz。每次只读取最新一帧，不按到达顺序补处理旧帧。
- 连续 200 ms 未收到有效帧，置 `VISION_STALE`；`APPROACH` 和 `PUSH` 不得继续依据旧视觉位置前进。
- 空帧是有效帧，表示“当前视野无目标”，不是通信故障。
- `SEARCH` 可以在空帧下低速原地搜索；视觉失效时按安全策略停止追逐，并在 LCD 标明 `VISION STALE`。

## 6. UART5：LD06 雷达调度规则

### 接收与解析

- 保留现有 LD06 驱动、数据格式和点云显示能力，不重写已验证的协议层。
- UART5 中断/DMA 只接收数据；主循环以固定预算增量解析，禁止一次性耗尽所有积压字节。
- 一圈完整/可用点云产生后，发布“最新雷达快照”：点云时间戳、墙体定位结果、最近障碍方向与距离、动态障碍标记。

### 定位与避障

- 雷达定位以已知 3 m × 3 m 围墙的线/角匹配为主，IMU 航向为约束；不在第一阶段引入重型 SLAM。
- 与静态围墙地图不一致、持续移动的点簇可标记为敌方车或动态障碍。
- 雷达模块不生成任务目标；它只向安全层给出 `允许 / 降速 / 停车` 或速度上限。
- 雷达快照超过项目确认的安全阈值未更新时，底盘进入降速或停车。阈值在实车安装和雷达频率确认后写入配置，未标定前默认停车更安全。

## 7. UART7：松甲驱动板调度规则

### 发送

- UART7 是唯一的底盘运动下发口，松甲协议和四通道映射保持现有测试结论。
- 只有 50 Hz 底盘安全周期可以调用松甲发送接口。视觉、雷达、IMU、LCD、按键和任务状态机不得直接发送 `$Car`、`$Car_Pwm` 或电机参数命令。
- 状态机先产生“期望速度”，雷达安全层再限速，反馈超时安全层最后决定是否置零；下发的是这一份最终速度。
- 诊断模式 Task6 是例外：它只在任务独占、底盘自动状态机未运行时使用 UART7，并在退出时发送零速度和零 PWM。

### 接收与超时

- 以松甲编码器反馈作为链路与闭环健康度依据；接收缓冲由中断搬运，主循环解析。
- 反馈解析只更新最新四通道快照和时间戳，旧反馈不排队计算 PID。
- 松甲反馈超过配置的安全超时未更新时，立即置 `MOTOR_LINK_STALE`，最终 `vx/vy/wz` 归零并停止追逐目标。
- 编码器方向、比例和轮速换算尚未完成实车标定时，仅允许低速台架验证，不进入自动救援模式。

## 8. SPI：BMI088 IMU 调度规则

- SPI 以 100 Hz 调度 IMU 更新；单次读取失败必须立即返回，不得重试到阻塞。
- 发布姿态快照：航向、角速度、时间戳和有效标志。
- 定位模块使用 IMU 航向约束雷达墙体匹配；底盘可使用航向误差辅助原地搜索和对准。
- IMU 数据过期时禁止使用旧航向作高精度对准；低速安全停车或降级策略由安全层决定。
- IMU 校准、零偏和坐标方向必须沿用已验证流程；未确认的安装方向不能写成固定控制符号。

## 9. LCD 与按键调度规则

### LCD

- LCD 刷新目标为 4-10 Hz，推荐普通运行 5 Hz（200 ms）。
- 只刷新内容改变的行/区域；进入页面时可完整绘制一次，随后不得每圈清屏重画。
- LCD 显示优先级：`安全故障 > 当前任务状态 > 通讯新鲜度 > 底盘目标/反馈 > 调试信息`。
- 建议常驻显示：任务状态、`VISION/RADAR/MOTOR/IMU` 在线状态、最终速度、故障码；点云和详细调试仅在诊断任务显示。
- LCD 写入遇到总线慢或页面复杂时，必须继续分块完成，不能阻塞 20 ms 控制窗口。

### 五向按键

- 按键统一由 `InputService` 轮询和消抖，任务只消费 `InputEvent_t`。
- 自动救援运行时，上/下/右/中键不直接改变电机输出；仅允许进入明确的暂停、诊断或安全确认流程。
- 左键仍是任务退出与安全停机入口；任何模式下均不得被普通 UI 功能覆盖。

## 10. 任务状态机与安全层接口

```text
视觉/雷达/IMU/松甲反馈
          ↓ 最新有效快照
救援状态机（SEARCH/APPROACH/PUSH/VERIFY）
          ↓ 期望 vx/vy/wz
安全层（新鲜度、雷达障碍、限幅、急停）
          ↓ 最终 vx/vy/wz
UART7 松甲四通道命令
```

- `SEARCH`：无合规目标时只请求低速旋转；雷达可因障碍而限制或拒绝。
- `APPROACH`：以视觉 `x_px/y_px` 生成期望运动；视觉过期则停止接近。
- `PUSH`：只有夹爪区检测有效且障碍安全时才允许低速推进。
- `VERIFY`：物料类别/颜色符合预期且背景蓝色连续确认后，才登记任务完成。
- 危险品永不成为可推进目标；目标丢失 0.3-0.5 秒后放弃并重新搜索。

## 11. 联调与验收清单

- [ ] UART1 连续 10 分钟稳定接收空帧和 1-5 目标帧；CRC 错帧不污染有效快照。
- [ ] UART5 点云持续可用，雷达解析不造成按键或 50 Hz 底盘周期卡顿。
- [ ] UART7 在反馈超时后安全置零；诊断模式退出后不存在残留电机命令。
- [ ] SPI IMU 100 Hz 更新不影响 UART 收发；航向过期被正确标记。
- [ ] LCD 持续刷新时按键响应、串口接收和电机控制周期正常。
- [ ] 视觉、雷达、IMU 任一数据源失效时，底盘均不会继续凭旧数据高速运动。
