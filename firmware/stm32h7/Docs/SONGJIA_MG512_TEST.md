# 松甲四路编码器驱动板 / MG513P30 四轮测试说明

## 1. 目标与边界

菜单首位 `MG513 SONGJIA` 用于独立验证松甲四路编码器驱动板与四台轮趣 MG513P30 霍尔编码器电机、80 mm 麦克纳姆轮的方向、调速、急停和回传。它是底盘控制接入前的台架工具，不承担视觉、雷达或比赛策略。只保留松甲板原生 `$Car:` 速度闭环。

UART3 上原有泰山派 `A5 5A ... CRC8` 协议没有修改。UART1 已预留给泰山派视觉；松甲板使用 UART7。

## 2. 接线与串口

- 达妙 `PE8 / UART7_TX` -> 松甲 UART RX；
- 达妙 `PE7 / UART7_RX` <- 松甲 UART TX；
- 两板信号地必须共地；
- 串口参数为 `115200, 8 data bits, no parity, 1 stop bit`；
- 松甲板电机电源、电压范围、UART 电平和 MG513P30 编码器线序必须按实物丝印与手册复核，
  当前软件不能替代接线确认。

UART1 不再用于松甲。Task6 使用 UART7 的 RX/TX 中断环形缓冲；UART7 的引脚与 UART1 视觉输入分离，接线前仍需复核 UART 电平兼容性。

## 3. 松甲 UART 协议

协议为 ASCII 文本，以 `$` 开始、`!` 结束，无 CRC。Task6 使用以下命令：

| 功能 | 帧格式 |
|---|---|
| 选择 520 电机配置 | `$MOTOR_4CH_SET:0!` |
| 编码器极性保持默认 | `$MOTOR_4CH_SET_ENCPDER_POLARITY:0!` |
| 设置 MG513P30 速度换算参数 | `$MOTOR_PARAM:8,13,30!`（80 mm 轮径、13 线霍尔、30:1 减速比） |
| 板载速度闭环 | `$Car:A,B,C,D!`，单位 m/s |
| 开环 PWM | `$Car_Pwm:A,B,C,D!`，命令值为百分数 |
| 请求 20 ms 编码器增量 | `$MOTOR_4CH_READ:encoder_20ms!` |
| 编码器反馈 | `$MOTOR_4CH_Encoder_20ms:a,b,c,d!` |

`ENCPDER` 是资料协议中的原始拼写，不能改成 `ENCODER`。驱动公开的 PWM 接口使用
`-1000..1000` 千分比，发帧前换算为 `-100..100`；速度接口使用 cm/s 整数，发帧时换算
为 m/s 小数，避免依赖浮点 `printf`。

## 4. PID 与限制

当前电机为 MG513P30、霍尔编码器 13 PPR。传动比、松甲回传计数倍率、各通道方向与最终轮速换算均须以低速台架数据复核；不得根据旧 MG512 文档或线色直接固化结论。

安全限制：

- 板载闭环目标为 `-30..+30 cm/s`，上/下键每次变化 `5 cm/s`；最终装车参数须重新整定；
- 速度闭环测试仍持续下发 `$Car`，即使编码器反馈缺失；屏幕会提示 `RX: LOST`，但不以它阻断松甲板内部 PID 的连通性验证；
- 命令与编码器方向异常时必须进入故障并停机；
- 进入任务时目标为零，退出任务时再次发送零 PWM 与零速度。

## 5. LCD 与五向键

LCD 实时显示 `MODE`、`STATE`、目标转速、四通道反馈与串口收发状态：

Task6 进入时沿用 Task3 已验证的 `Display OFF -> 完整绘制 -> Display ON` 流程；之后每
250 ms 至多检查一次，只有内容发生变化的行才重画，避免 LCD 的同步写入阻塞按键与串口处理。

- 上键：增加目标，并直接按新目标启动或调速；
- 下键：降低目标，可跨过零测试反向，并直接按新目标启动或调速；调回零即停机；
- 右键：立即发送四路零 PWM 和零速度，作为本任务的急停；
- 中键：本任务不使用；
- 左键：由 TaskManager 拦截，先执行 Task6 零输出，再执行全局安全停机并返回菜单。

## 6. 建议实机顺序

1. 架空四个车轮或拆除机械负载，所有目标保持为零进入 Task6；
2. 分别低速测试 A/B/C/D 的正负方向和编码器回传；
3. 验证正负切换、调速、零指令停车、右键急停和通信超时停车；
4. 再测试四通道同时运行及麦克纳姆轮方向组合；
5. 仅在以上项目通过后才允许接入统一底盘速度接口。未完成这些观察前，只能报告“编译通过”，不能报告
   “MG512 闭环验证通过”。
